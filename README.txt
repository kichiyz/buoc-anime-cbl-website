BUOC Official Website
Bicol University Otaku Circle
Academic Year 2026–2027

Welcome to the official website of the Bicol University Otaku Circle (BUOC). This website contains information about the organization, its officers, committees, and Constitution and By-Laws.

Live Website:
https://kichiyz.github.io/buoc-anime-cbl-website/

Website Features

Organizational Information
- Introduction to the Bicol University Otaku Circle.
- Responsive website layout for desktop, tablet, and mobile devices.

Officers Directory
- Organizational chart showing the officers and their positions.
- Separate listings for Business Managers and Campus Representatives.
- Campus assignments for Campus Representative Chiefs and Deputies.
- Clickable officer profiles containing available information about their positions, duties, and terms of service.
- Photo placeholders for officers whose pictures are not yet available.

Committee Directory
- Information about the Secretariat, Finance, Planning, Public Relations and Human Relations (PR-HR), and Ways and Means committees.
- Committee leadership, objectives, advocacy, and responsibilities.

Constitution and By-Laws
- View the organization's Constitution and By-Laws directly through the website.
- The PDF file is located at assets/BUOC_CBL_Clean.pdf.

Repository Files

- index.html — Main website page.
- assets/ — Officer photographs, committee logos, and other website resources.
- assets/BUOC_CBL_Clean.pdf — Constitution and By-Laws document.
- .nojekyll — Configuration file for GitHub Pages.

Updating the Website

1. Open the existing repository:
   https://github.com/kichiyz/buoc-anime-cbl-website/
2. Edit index.html or update the necessary files in the assets folder.
3. Keep the existing folder structure and file paths.
4. Commit the changes to the main branch.
5. Wait for GitHub Pages to publish the updates.
6. Open the live website and check that the changes work on desktop and mobile devices.

GitHub Pages is configured to publish the website from the main branch. There is no need to create another repository for future updates.

Note

The website and its files may be publicly accessible. Make sure BUOC has permission to publish its Constitution and By-Laws, officer photographs, and organizational information.
