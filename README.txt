# BUOC — Official Website

**Bicol University Otaku Circle (BUOC)**  
*Official Organization Website | Academic Year 2026–2027*

Welcome to the official website of the Bicol University Otaku Circle! This website provides information about the organization, its officers, committees, and Constitution and By-Laws (CBL).

🌐 **Live Website:** https://kichiyz.github.io/buoc-anime-cbl-website/

## ✨ Website Features

### 🏛️ Organizational Information
- Anime-inspired design reflecting the identity of BUOC.
- Responsive layout for desktop computers, tablets, and mobile devices.
- Organization information and introductory welcome page.

### 👥 Officers Directory
- Dedicated Officers Directory accessible through a website button.
- Organizational chart inspired by BUOC's leadership structure.
- Officers organized by leadership positions, committees, Business Managers, and Campus Representatives.
- Separate listings for Campus Representative Chiefs and Deputies, including their assigned campuses.
- Clickable officer profiles displaying available information, including positions, responsibilities, term of service, and additional notes.
- Centered square photo frames designed to minimize portrait cropping.
- **PHOTO COMING SOON** placeholders for officers whose photographs are unavailable.

### 🗂️ Committee Directory
- Interactive committee profiles.
- Committee leadership, advocacy, objectives, and responsibilities.
- Information for the Secretariat, Finance, Planning, Public Relations & Human Relations (PR-HR), and Ways and Means committees.

### 📜 Constitution and By-Laws
- Dedicated **View Constitution & By-Laws** feature.
- Embedded PDF viewer for the organization's Constitution and By-Laws.
- PDF file located at `assets/BUOC_CBL_Clean.pdf`.

## 🚀 Deployment and Updates

This website is hosted using **GitHub Pages**.

### GitHub Pages Configuration
1. Open the repository: https://github.com/kichiyz/buoc-anime-cbl-website
2. Navigate to **Settings → Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Set the branch to `main` and the folder to `/(root)`.
5. Save the configuration if changes are necessary.
6. Wait for GitHub Pages to publish the latest commit.

The published website is available at:

https://kichiyz.github.io/buoc-anime-cbl-website/

### Updating Website Files
1. Edit the existing `index.html` or the relevant assets.
2. Upload or commit the updated files to the existing repository.
3. Preserve the directory structure and all referenced asset paths.
4. Commit and push the changes to the configured publishing branch.
5. Wait for deployment to complete.
6. Test the updated website on desktop, Android, and iOS devices.

**Important:** Upload the contents of the website package, not merely the ZIP archive. Keep `index.html` and `.nojekyll` at the repository root, and preserve the `assets` directory.

## 📱 Responsive Design and Compatibility

The website is designed to accommodate different screen sizes and input methods. However, PDF viewing, image rendering, and other browser-dependent features may behave differently across devices.

After significant updates, test:
- Officers Directory navigation and organizational chart layout.
- Officer photographs and missing-photo placeholders.
- Clickable officer and committee profiles.
- Mobile scrolling and responsive layouts.
- The Constitution and By-Laws viewer across supported browsers.

## 🔗 QR Code Access

A QR code may be used to direct members to the public website.

- Generate the QR code using the final, working HTTPS website URL.
- Verify the QR code on multiple devices before distributing it.
- Remember that the QR code points to the website; it does not contain the entire website or PDF.

## 🔒 Public Access and Privacy

GitHub Pages websites hosted in public repositories are accessible on the internet. Before publishing, ensure BUOC is authorized to make the Constitution and By-Laws, officer names, photographs, and other organizational information publicly available.
