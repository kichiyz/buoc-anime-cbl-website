BUOC Official Website

Welcome to the official website of the Bicol University Otaku Circle (BUOC). This website provides information about the organization, its officers, committees, and Constitution and By-Laws.

Live Website
https://kichiyz.github.io/buoc-anime-cbl-website/

Website Features

1. Organizational Information

The website introduces BUOC and provides information about the organization through a responsive layout designed for desktop computers, tablets, and mobile devices.

2. Officers Directory

The Officers Directory presents the organization's officers through an organizational chart. Officers are grouped by leadership positions, committees, Business Managers, and Campus Representatives.

Campus Representatives are listed by role and assigned campus. Selecting an officer opens a profile containing available information about their position, duties, term of service, and other details. Officers without available photographs are displayed with a photo placeholder.

3. Committee Directory

The website includes interactive profiles for the Secretariat, Finance, Planning, Public Relations and Human Relations (PR-HR), and Ways and Means committees.

Each committee profile provides available information about its leadership, objectives, advocacy, and responsibilities.

4. Constitution and By-Laws

Visitors can access the organization's Constitution and By-Laws through the website's built-in viewer.

The PDF file is located at assets/BUOC_CBL_Clean.pdf.

Website Deployment and Maintenance

The website is hosted using GitHub Pages from the main branch of the existing repository.

Repository:
https://github.com/kichiyz/buoc-anime-cbl-website

Published Website:
https://kichiyz.github.io/buoc-anime-cbl-website/

To update the website, edit the necessary HTML or asset files and commit the changes to the main branch. Preserve the existing folder structure and file paths to ensure that photographs, committee logos, and the CBL viewer continue to work.

After publishing updates, check the website on desktop and mobile devices. Test the Officers Directory, officer profiles, committee profiles, navigation buttons, and Constitution and By-Laws viewer.

QR Code Access

A QR code may be generated using the published website URL. Test the QR code on multiple devices before distributing it. The QR code directs visitors to the website; it does not contain the entire website or PDF.

Public Access and Privacy

The website and its files may be publicly accessible through GitHub Pages. Ensure that BUOC is authorized to publish its Constitution and By-Laws, officer photographs, and organizational information.
